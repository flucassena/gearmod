## What's new in 0.3.0

Cards now explain their complexity before you pick a flow, agents tell you when they need you, and the whole interface follows one look for colors and icons, in dark and light.

### Highlights

- **Complexity and decisions.** Before scoring a card, the planner explores the code and asks up to three questions that change the estimate. The score shows up in the chat as a card with the score table and the flow options by gear (light, spec, full SDD), with the AI recommendation marked with ✦. You confirm the choice and the card stays in the chat history, collapsed. The **Complexity and decisions** dialog has a summary of the score, a list of assessment versions with what changed, the critical risks (new, kept and gone) and the decisions. Pending decisions and the score also show on the card, in the editor and beside the planning chat.
- **Agents tell you when they need you.** The card glows, a system notification goes out, the quick view flags it and the project lists its alerts on hover.
- **Automated tests per repository.** A new **Tests** tab in the project sets the test command of each repository with an agent chat. The tests run in the card worktree, only for the repositories the card changed, and the agent can read and set the command.
- **Design system.** Every state has one color everywhere (info, success, warning, danger, plan) and every icon has one drawing and one meaning, with the same thin stroke and size. A new theme editor lets you build your own theme with a preview.
- **Conflicts and pull requests.** Conflicts can be resolved line by line or with an agent, and pull requests open in the middle of the Git screen.

### Agents

- The permission mode can be changed while the agent runs; it applies right away, without waiting for the turn to end.
- The agent can amend the last commit of the card branch, or only reword its message, through the commit request.
- A failed run shows on the card and can be retried with another agent.
- Planning continues on its own after you approve the flow.
- Claude installed through npm on Windows is recognized, and agents install inside the app.
- Claude's answer after a background task is no longer lost, and resuming a session ignores an empty result.

### Cards and the flow

- A card in Done with something left over gets a **Finalize** button, and moving a card to Done offers to delete its worktree and branch, warning first if commits or files would be lost.
- Worktrees are deleted in the background (the dialog can be closed), without ever emptying the packages that `node_modules` links point to. Worktrees made outside GearMod can be deleted from the Git screen.
- Each repository has its own base branch; cards start from its latest version and keep only the repositories they change.
- The card decisions show beside the planning chat, foldable, with the number, status and kind on one line.
- The planning chat opens beside the board with suggestions.

### Chat

- The **Chats** page shows one row per card, with a button per step (planning, implementation, test).
- The Copy buttons work again, and the run and copy buttons of code blocks no longer cover the code.
- The reply field has a visible border and grows with the text.
- Chat search moves between results with the arrow keys.
- In the image preview, the close button sits on the image's corner, away from the window's close button.

### Git

- The commit panel shows the date and time next to the parent, and the graph has a **Date** column at the end, in the app language.
- Clicking a branch in the sidebar lights only the commits it reaches.
- The card popover in the graph is no longer clipped, and the changes panel fits when narrow.
- A remote branch folder has a menu to delete all its branches on the server, after confirming the list.
- A refused force push says where the remote is.

### Settings and the app

- The Playwright install and the browser download show the step running and a progress bar.
- Spec Kit shows which version wrote the project files and offers the update only when they are old.
- Storage shows each bar's share, backups are ordered by date and can all be cleared at once.
- A standard loading state with the thinking mascot.
- The usage list shows the weekly limit beside the session.
- Clicking the open project in the sidebar goes back to its board.

### Fixes

- The sidebar shows one status per project (needs you, then finished, then running), so the row no longer overflows.
- The background tasks menu stays inside the window, and menus close when the page scrolls.
- The background task spinner stays round.
- The conflict resolver uses the app's checkbox to pick a whole side.
- The install commands on the download page no longer have a code border.

### Upgrading

GearMod 0.2.0 finds this version by itself and offers to update. Your projects, cards and settings are kept.
