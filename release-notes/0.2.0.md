## What's new in 0.2.0

GearMod now runs on **Linux** and, as a preview, on **macOS**. It also updates itself, runs Spec Kit inside the app and makes many parts of the daily flow easier.

### Highlights

- **Linux (x64).** An AppImage for any distribution and a `.deb` for Debian, Ubuntu and derivatives. The site has a download page and a one-command installer. The app reads your shell's PATH, so CLIs installed with nvm, npm or `~/.local/bin` are found even when GearMod is opened from the applications menu.
- **macOS (preview).** Disk images for Apple Silicon and Intel, macOS 12 or later. They are built for every release but have not been tested by users yet. The window uses the native buttons, the menu bar has Edit and Window (so Cmd+C and Cmd+V work), shortcuts use Cmd, and signing in to an agent opens Terminal. The first launch needs one command in Terminal (see Download below).
- **Automatic updates.** GearMod looks for a new version on start and every 6 hours. On Windows it downloads the installer, checks its SHA-256 and runs it. On Linux it replaces the AppImage or installs the `.deb`. On macOS it opens the release page. The new **About** tab shows the version, the system and what the latest release brings.
- **Spec Kit inside the app.** Installing uv and the Spec Kit CLI, updating them and starting Spec Kit in a folder run in a dialog with a built-in terminal. Steps that ask questions stay open. You can close the dialog and the step keeps running under Processes. Starting Spec Kit in a folder that is not a repository runs `git init` first. The SDD tab then points to that repository and its Constitution without any setup.

### Agents

- Adding an agent is now step by step: type (Claude or Codex), name, usage and personality. Signing in runs in a small terminal inside the app. The browser opens by itself and the dialog notices when the account is connected.
- Updating Claude or Codex runs inside the app with progress, and can go on in the background.
- Switching a card's agent keeps an equivalent model.
- A project with no agent invites you to add one.
- Codex sign-in no longer fails when its `CODEX_HOME` folder does not exist yet.
- Any color can be picked for an agent, and new agent defaults follow the interface language.

### Cards and the flow

- The tester's failed checklist items can be sent to the developer with one click, and they go into the developer's context. A change the tester proposes and you approve is implemented by the developer.
- The executions panel has a **History** view with the card's runs in order, so the back and forth between planning, implementation and test is visible.
- A card moves to the Test column when its test starts.
- The card's branch is named after its title once it has one.
- The planner no longer creates tasks the developer cannot do.
- The test command is suggested from the project files.
- The scope warning can ignore folders and folds its file list.
- An empty card title is marked on the field, and the save button explains why it is disabled.

### Chat

- Attachments open: images in a preview over the window, other documents in the system's app (never executables or scripts).
- Markdown lists continue when you press Enter in the chat box.
- The answer in progress shows again when you come back to a chat.
- The short flow stays in a single chat.

### Projects, Git and settings

- Repositories can be added to or removed from a project after it is created.
- Worktrees created outside GearMod are listed and can be used by a card.
- A local branch can be renamed from the branch menu, and the rebase targets the card's new base branch.
- GitHub and GitLab errors are explained in plain language (proxy pages, DNS, certificate, timeout, rate limit).
- **Connectors** (MCP) have a new layout, support SSE servers and can import a JSON configuration. The discover cards are fully clickable.
- New **Storage** tab: how much space the app's tools, browsers, voice models, backups and downloaded updates take, with removal for what can be downloaded again.
- Playwright's version list floats above dialogs and marks the version in use and the installed ones.
- Save, find, replace, go to line and the database reload and cancel keys can now be changed in **Settings › Shortcuts**.
- New tool versions are announced without a manual check.
- The first run starts in the system language.
- The main window opens as it was left, and maximized the first time.
- The agents look at the code index first. A benchmark (`bench/`) measures what the index adds.

### Database

- The empty Database page has a welcome card.

### Fixes

- The in-app terminal is included in the Linux packages, and the window buttons area follows the theme on Linux.
- On Linux and macOS, uv and `specify` are found right after Spec Kit installs them, without restarting the app.
- Context menus stay open when the window loses focus.
- The project name stays in place when the side menu collapses.
- The taskbar icon follows the theme color.
- A long base branch name stays inside the card's branch box.
- The Constitution reloads after its folder changes.
- The app uses its own dialogs and tooltips instead of the system ones.

### Upgrading from 0.1.0

Version 0.1.0 does not check for updates, so download this version once from the links below. Your projects, cards and settings are kept. From 0.2.0 on, GearMod tells you when a new version is out.
