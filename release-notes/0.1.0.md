## GearMod 0.1.0

The first public version of GearMod, for **Windows 10 or 11 (x64)** only.

### Download

- Run **GearMod-Setup-0.1.0-x64.exe**. It installs per user, with no admin rights.
- The installer is not code-signed yet, so Windows SmartScreen may show "Windows protected your PC". Click **More info** and then **Run anyway**.
- You can check the download against `SHA256SUMS.txt` with `Get-FileHash .\GearMod-Setup-0.1.0-x64.exe -Algorithm SHA256`.

### Good to know

- This version does not check for updates. Install 0.2.0 or later once to get automatic updates.
