## What's new in 0.4.0

This version adds pull and merge request review inside the Git screen, card attachments, a collapsed menu that stays useful, silent background updates and Gemini through the Antigravity CLI.

### Git and reviews

- Review PRs and MRs inside the Git screen: file tree, line comments, reactions and merge.
- Push and pull the branch picked in the Git side list, not only the checked-out one.
- Suggest the commit message with AI on the Git page, with Haiku or Codex's lightest model, and keep each repository's commit message convention so agents follow it.
- Unpick the side branch by clicking elsewhere and edit the last commit message inline.
- A branch being deleted shows a red spinner and is locked until it ends.

### Cards

- Each card has an Attachments folder: add files with a button, by dragging or with Ctrl+V, see them as thumbnails or as a list with file type icons, use them in the chat, and open text files in GearMod's own viewer. Done cards can clear their files.
- The initial side chat can be turned off in Settings, and turns itself off after 5 unused closes.
- The test stage only offers "send to fix" for items that really failed. What the tester could not verify shows a neutral "pending" badge instead.
- Deleting a card's worktree on Windows no longer fails because of open file watchers: GearMod lets go of the folder and retries the move.
- Errors from restarting or deleting a chat appear as a toast.
- The planning run shows on the card tile like the other runs, and a project's finished count follows the same rule as its hover list.

### Menu and look

- The collapsed left menu is now an icon rail with the status on each avatar, the name and alerts on hover, and the session usage panel on hover.
- Checkbox marks use the on-accent color, and creating a card manually focuses its title.

### Agents and updates

- Gemini runs through the Antigravity CLI, with its quota, account models and agent controls.
- A permission request can allow everything from now on, with automatic approval per conversation.
- The update downloads in the background and installs silently, reopening GearMod by itself.
- Each new Spec Kit version is checked against what GearMod relies on before updating, using the verdicts a daily CI job publishes.
- A closed console pipe no longer crashes the app with an EPIPE error.

### Upgrading

GearMod 0.3.1 finds this version by itself and offers to update. Your projects, cards and settings are kept.
