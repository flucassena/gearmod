Ícones · padrão e o que foi unificado

Todo ícone vem de icons.tsx (família do banco em DbIcons.tsx) com a classe .ico: traço fino de --icon-stroke (1.5px) igual em qualquer tamanho, pontas e cantos arredondados, sem preenchimento (só pontinhos são cheios). A tela escolhe só o tamanho e a cor.

  1. ✦ é só IA. Planejar ganhou PlanIcon (quadro, novo card, cabeçalho do plano).
  2. Novo chat = ChatPlusIcon na página de Chats e na barra lateral (antes ✦ e +).
  3. Abrir card = CardIcon em todo lugar (o olho saiu do menu do card e ficou só para "visualizar"); as três cópias do desenho no tile e no chat viraram o mesmo ícone.
  4. Worktree = árvore (TreeIcon) em todo lugar (chip do chat, arquivos, chip de Git do editor); o WorktreeIcon (quadradinhos) saiu. Branch e Git continuam com BranchIcon.
  5. Token de acesso = chave (KeyIcon) nas contas Git; moedas (TokenIcon, redesenhado) só para o consumo do agente.
  6. Banco = um desenho só (DatabaseIcon); o do DbIcons usa o mesmo e só muda de cor com a conexão.
  7. Arquivos alterados = só o quadradinho (DiffIcon); a setinha saiu da linha. A setinha é só para abrir/fechar.
  8. Cópias viraram ícones: 3 lupas diferentes → SearchIcon; setas, anterior/próxima, comentar, enviar, salvar, copiar, terminal, avisos do toast etc. (~45 desenhos em 41 arquivos).
  9. Continua igual de propósito: o X de "Ocultar terminal" (é fechar o painel, não a visão rápida, que usa a setinha).

Onde cada um é usado

Gerado do código: icons.tsx, DbIcons.tsx e cada <svg> escrito dentro de um componente. "Para quê" vem do rótulo do botão (aria-label, data-tip, title ou texto ao lado); "(?)" marca um texto incerto (a mesma chave tem textos diferentes no pt-BR).
